# Project Handbook

This directory contains the durable product and engineering context for the
data-center schematic and CAD application. Start with [`../AGENTS.md`](../AGENTS.md),
then load only the guides relevant to the task.

## Start Here

- [`../PROJECT_PLAN.md`](../PROJECT_PLAN.md): staged MVP and future phases
- [`product/design.md`](product/design.md): visual language, UX principles, and
  design review checklist
- [`engineering/frontend.md`](engineering/frontend.md): compact React,
  ReactFlow, viewer, accessibility, and frontend performance rules
- [`engineering/README.md`](engineering/README.md): engineering subject map

## Documentation Rules

- Keep this handbook short enough for an AI agent to search and load selectively.
- Use headings that name a concrete subject or behavior.
- Put durable rules in the most specific relevant document.
- Explain the reason for a non-obvious rule and name meaningful exceptions.
- Do not copy implementation details that are not currently true.
- Update cross-references when paths, tools, or architecture change.
- Keep temporary plans and unresolved options out of canonical rules.
